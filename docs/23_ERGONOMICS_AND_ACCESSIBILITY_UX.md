## 1. High-Pressure Incident Ergonomics

During a major SEV-1 outage, engineers operate under extreme cognitive load and stress. UI friction causes mistakes. MAYDAY implements ergonomic safeguards:

1. **High Contrast Color Tokens:** Minimum 7:1 contrast ratio across all text and background elements, exceeding WCAG AAA standards for critical telemetry.
2. **Distinct Audio Cues:** Each state change (alert, falsification, pass) has a distinct harmonic signature.
3. **Large 48px Touch Targets:** All interactive buttons meet or exceed the 48×48px mobile touch envelope.
4. **Keyboard Accessibility:** Complete navigation supported via standard Tab / Enter / Escape keys.
