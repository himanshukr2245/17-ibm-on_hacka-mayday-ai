# Security Policy

## Reporting Security Issues

Please report any security issues or vulnerabilities found in this project by contacting the repository maintainers directly.

## Protecting Credentials

- **NEVER** commit `.env` files or real API keys to this repository.
- Ensure all sensitive keys are listed in `.gitignore` and `.bobignore`.
- If IBM Cloud credentials are accidentally committed, revoke and regenerate them immediately in the IBM Cloud console.
